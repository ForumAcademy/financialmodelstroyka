# Финансовая модель девелопера — спецификация

Универсальный шаблон оценки потенциала земельного участка под жилую застройку в РФ. Этот пакет — спецификация для разработки веб-сервиса в Claude Code (GitHub + Vercel). Каждая цифра модели привязана к источнику со ссылкой.

## Что внутри

| Путь | Содержание |
|---|---|
| `CLAUDE.md` | Правила для Claude Code |
| `docs/00_principles.md` | Трассируемость, шкала источников 1–5, соглашения |
| `docs/01_architecture.md` | Стек, структура репозитория, ядро, БД |
| `docs/02_legacy_audit.md` | Аудит исходного Excel: 18 критических ошибок с адресами ячеек |
| `docs/03_formulas.md` | Каталог формул: выражение, почему так, что отклонено, источники *(генерируется)* |
| `docs/04_parameters.md` | Реестр параметров и статей бюджета *(генерируется)* |
| `docs/05_sources.md` | Реестр источников со ссылками *(генерируется)* |
| `docs/06_build_plan.md` | Этапы разработки с готовыми промптами и критериями приёмки |
| `data/*.yaml` | Источник правды: sources, parameters, capex_items, regions (89 субъектов), formulas |
| `legacy/` | Исходный Excel + полная карта его ячеек (737 значений, 686 шаблонов формул на 5 547 ячеек, 467 текстовых ячеек) |
| `tests/cases/derbenevskaya_legacy.yaml` | Входы исходника, цели сверки, обязательные отличия после исправлений |
| `scripts/` | Валидатор, генератор документации, построение карты legacy |
| `packages/spec`, `packages/engine`, `apps/web` | Монорепо pnpm: справочник, расчётное ядро, веб-интерфейс (Next.js) |

## Быстрый старт

```bash
pip install pyyaml openpyxl
python scripts/validate_spec.py   # 0 ошибок, список того, что сверить перед релизом
python scripts/render_docs.py

# веб-сервис (Node.js 22+, pnpm 10)
pnpm install
pnpm typecheck && pnpm lint && pnpm test
pnpm dev                          # http://localhost:3000
```
