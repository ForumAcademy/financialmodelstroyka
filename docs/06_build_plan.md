# План реализации в Claude Code (GitHub + Vercel)

Каждый этап — отдельная ветка и PR с preview на Vercel. Промпт копируется в Claude Code как есть. Этап не начинается, пока не принят этап перед ним.

## Этап 0. Репозиторий

1. Создать пустой репозиторий на GitHub, подключить к Vercel (Import Project).
2. Скопировать содержимое этого пакета в корень, закоммитить в `main`.
3. Промпт:

> Прочитай CLAUDE.md и docs/00–02. Настрой монорепо pnpm: packages/spec, packages/engine, apps/web (Next.js App Router, TypeScript strict). Добавь GitHub Actions: python scripts/validate_spec.py, pnpm typecheck, pnpm lint, pnpm test. Ничего не считай — только каркас.

**Приёмка:** CI зелёный, preview открывается.

Настройка Vercel (один раз, делает владелец репозитория): Add New → Project → Import `financialmodelstroyka`, Root Directory = `apps/web`, остальное по умолчанию. После этого Vercel сам создаёт preview для каждого PR.

## Этап 3. CAPEX

> Реализуй F.CAPEX.* и справочник capex_items.yaml: ставка × база × индекс, правила графика uniform / s_curve / at_milestone / follow_smr / follow_sales / manual. Проверки SCHEDULE_SUM и BUDGET_EQ_CF. Расчёт «как в исходном Excel»: ручные квартальные ряды из capex_legacy.

**Приёмка:** сумма весов = 1 для каждой статьи; УДС и «Прочие СМР» попадают в CF.

**Решения владельца продукта 27.09.2026 (внесены в data/*.yaml):**
- **Очереди:** один график на статью — от самой ранней вехи «с» до самой поздней вехи «по» среди всех очередей (F.CAPEX.SCHEDULE_WEIGHT); деление по очередям пропорционально площади — отложено.
- **НДС по статьям:** у каждой статьи `vat_rate` (TAX.VAT_RATE или 0 / 0,05 / 0,07 / 0,22 — TAX.VAT_RATE_OPTIONS), условные `vat_rules`, для смешанных — `vat_taxable_share`. Покупка участка — 0 (пп.6 п.2 ст.146 НК РФ; уступка права аренды — 0,22, не сверено); земельный налог — вне НДС, аренда государственной / муниципальной земли — 0, у частного собственника — 0,22 (LAND.LESSOR_TYPE); плата за ВРИ — 0; обязательства перед городом разделены на CITY_CASH_COMPENSATION (0) и CITY_OBJECTS_CONSTRUCTION (0,22); в расчёте «как в исходном Excel» Бюджет!F24 «Компенсация городу» (1 260 033 986,66) целиком — CITY_CASH_COMPENSATION: объекты для города уже есть статьями SOCIAL_OBJECTS и ROADS_UDS; содержание застройщика — облагаемая доля OPEX.OVERHEAD_VAT_SHARE; прочие работы и услуги — 0,22.
- **Статьи «в месяц»** (SITE_SECURITY, DEVELOPER_OVERHEAD): ставка в месяц × месяцы между вехами, неполные месяцы — по дням, индексация помесячно (F.CAPEX.ITEM_TOTAL).
- **Индексы:** CAPEX.COST_INDEX — дефлятор инвестиций МЭР (2026–2029: 6,5 / 5,0 / 4,1 / 4,1%), CAPEX.OPEX_INDEX — ИПЦ (5,6 / 4,0 / 4,0 / 4,0%); после 2029 — последнее значение (допущение). У каждой статьи `index_type`: investment | cpi | none. Статьи с базой «доля от другой суммы» не индексируются (none): от выручки — MARKETING, BROKERAGE, DEV_FEE; от СМР — TECH_CUSTOMER, AUTHOR_SUPERVISION, TECH_SUPERVISION, CONTINGENCY (иначе двойной счёт роста цен).
- **Расчёт «как в исходном Excel»:** доля квартала из ручных рядов исходника делится поровну на три месяца; индексации нет (суммы исходника в ценах исходника, эффект индексации — отдельной строкой F.CAPEX.INDEX_EFFECT); аренда/налог ЗУ и плата за ВРИ — суммы исходника (Бюджет!F21 по CF1 строке 24, Бюджет!F22 в квартал CF1!K26); суммы исходника — с НДС (допущение CAPEX.LEGACY_AMOUNTS_WITH_VAT, S_EXPERT). Аренда «поквартально авансом»: неполные кварталы — по дням, за неполный первый — в первый месяц аренды (решения владельца продукта 27.09.2026).
- **Горизонт** вычисляется (F.CF.HORIZON): max(последняя продажа, раскрытие эскроу последней очереди, погашение долга, уплата налога на прибыль за последний год) + 3 мес.; предупреждение, если > 180 мес. До этапов 4–6 — предварительный.
- **Аренда участка:** LAND.RENT_PAYMENT_FREQ (по умолчанию поквартально авансом), LAND.RENT_INDEXATION (по договору), окончание аренды — LAND.RENT_END_MILESTONE (по умолчанию начало передачи помещений первой очереди, needs_verification).
- **Смена ВРИ:** новая веха `vri_change_date`: до неё — кадастровая стоимость до смены ВРИ без коэффициентов п.15 ст.396, с неё — новая стоимость и коэффициенты; LAND_VRI платится в её месяц.
- **Парковка апартаментов:** TEP.PARKING_NORM_APART — значение + единица («на единицу» | «на 100 м² площади») из РНГП региона; для «на единицу» — TEP.APART_COUNT.

- заявка проходит путь «подана → принята → в опубликованной версии» или «отклонена с комментарием», всё видно в журнале.

**Приёмка:** выгрузка демо-проекта и любого созданного проекта открывается в Excel без ошибок и предупреждений о восстановлении; итоги совпадают с сервисом до рубля; ссылки на листе «Источники» кликабельны; на обложке указаны версия проекта и версия справочника; последний используемый столбец листа CF — последний месяц модели.
